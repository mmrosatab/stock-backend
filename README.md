# stock-backend

This is java spring boot application to manage a stock.

Initially this application was development with H2 Database. H2 Database is a database in memory, 
this meaning that when the application is turn off, the database is deleted or cleaned.
In other words, all data saved in database is lost.

The implementation with H2 database is in v1/stock branch.

The implementation with H2 database is in v2/stock branch.

## H2 Database

You can change h2 database properties in src/main/resources/application.properties
